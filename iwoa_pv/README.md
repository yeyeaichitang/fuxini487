# IWOA CEEMDAN VMD BiLSTM 光伏预测

本目录按技术说明书的组合模型路线训练光伏有功功率预测器。输入是连续 16 条、间隔 15 分钟的温度、气压、湿度、辐照度和实测功率，目标是下一 15 分钟的功率，单位 MW。四个环境字段均参与神经网络计算。

## 数据与处理

本次使用现有 `site_1_b` 电站，容量按源文件声明为 50 MW。该容量尚待电站资料独立确认，源数据时间没有已核实的时区。

沿用清洗数据的时间划分，训练期截至 2020-01-01，验证期为 2020-01-01 至 2020-04-01，之后为测试期。每个样本的全部历史与目标均须在同一分区，且连续、有效。四个环境字段的标准化参数只从训练样本拟合。

用最近已观测辐照度大于 20 W/m² 筛选日间预测起点，不使用未来目标功率筛选。得到 14,169 条训练、3,501 条验证和 8,849 条测试样本。推理入口同样检查这一适用条件。

每个预测窗口独立进行 CEEMDAN 分解，第一分量作为高频分量，其余合并为低频和残差。对高频分量做 VMD，将各模态与重构残差、低频分量及五个原始输入一起送入 BiLSTM。窗口内的双向学习范围限于已经观测的历史。

CEEMDAN 使用 16 次噪声试验、epsilon=0.005、max_imf=3 和固定随机种子 42。VMD 使用 tau=0、DC=0、init=1、tol=1e-6。为保持原信号可恢复，保留 VMD 的重构残差。

## IWOA 的具体实现

说明书没有给出改进鲸鱼算法的完整公式。本实现选择反向初始化、二次收敛因子和精英高斯扰动，作为明确可复现的研究变体。

- 种群 4，迭代 4 代，每个候选训练最多 6 轮，以验证集 RMSE 选择参数。
- VMD alpha 搜索 500 或 2000，模态数搜索 2 或 3。
- BiLSTM 单方向隐藏节点搜索 16、32 或 64，学习率在 10^-3.5 至 10^-2.2 搜索，权重衰减在 10^-6 至 10^-3 搜索。
- 完整组合与 VMD 消融各进行一次独立搜索。搜索日志记录实际参数和验证误差。
- 参数选择后，每组最终训练最多 60 轮，验证集连续约 12 轮无改善时提前停止，恢复验证误差最小的权重。

BiLSTM 为单层双向网络，以双向最终隐状态预测最近历史功率的修正值。四组方法采用相同的残差预测结构、损失函数和批大小。输出限制在 0 至站点容量范围。这里的“微调”在新路线中对应参数优化和网络训练。

## 对比实验

四组方法在同一时序划分上评估，另提供持续性基线。

| 方法 | 输入分解 | 参数来源 |
|---|---|---|
| IWOA–CEEMDAN–VMD–BiLSTM | CEEMDAN 高频再 VMD | 验证集 IWOA 搜索 |
| CEEMDAN–VMD–BiLSTM | 同上 | 固定默认参数 |
| IWOA–VMD–BiLSTM | 对历史功率直接 VMD | 独立验证集 IWOA 搜索 |
| BiLSTM | 原始五字段 | 固定默认参数 |
| Persistence | 最近历史功率 | 无训练 |

最终指标、逐样本预测和对比图写入 `models/iwoa_ceemdan_vmd_bilstm_v1/`。测试集不参与 IWOA 搜索、标准化拟合或训练早停。

## 运行

可在兼容 Python 环境安装 `requirements.txt` 后运行。原开发机使用 Python 3.12、PyTorch 2.11.0+cu128，分解依赖保存在 `output/iwoa_dependencies/`，本地运行会自动加载该目录。

```powershell
.\output\python312-runtime\python.exe iwoa_pv/train.py --workers 4
.\output\python312-runtime\python.exe iwoa_pv/predict.py --input models/iwoa_ceemdan_vmd_bilstm_v1/example_input.json --output output/iwoa_prediction.json
```

训练拒绝覆盖已完成的输出。更换输出时使用 `--output`。分解缓存为本机加速文件，更换源数据或分解配置后应指定新的缓存路径或清理对应缓存。完整训练需要项目本机的清洗数据文件。

预测加载保存的完整 BiLSTM 权重，在 CPU 上进行分解和推理。模型输入必须提供真实历史功率和四个环境字段，缺失值、容量替换和未知站点均会被拒绝。

## 适用范围与后续核对

本次是现有 50 MW 数据条件下的单站研究实验。说明书中的 10 MW 目标站需要另外提供对应数据与站点资料。16 点窗口仅覆盖 3 小时 45 分钟，对更长尺度的模态分析仍需进一步验证。IWOA 搜索预算、CEEMDAN 试验次数和默认超参数均为本次明确选定的配置，团队可据此复现实验和扩大搜索。

硬件接入、DG1～DG3适配及后端联调仍需分别验证。应以实际测试结果判断组合模型与各基线的性能。

算法实现参考 [PyEMD CEEMDAN 文档](https://pyemd.readthedocs.io/en/latest/ceemdan.html)与 [vmdpy 上游代码](https://github.com/vrcarva/vmdpy)。
